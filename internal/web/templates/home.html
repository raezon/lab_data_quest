Les services tournent sur la plateforme de la classe : vous vous y connectez depuis votre poste avec l'AWS CLI (installation ↗){{if .Cfg.S3Console}}, ou, pour S3, avec la console web de MinIO{{end}}.

{{if .Cfg.S3Console}}{{end}}

Console web MinIO{{.Cfg.S3Console}} — mêmes identifiants

Identifiants, à saisir une fois dans votre terminal (ou via aws configure) :

export AWS_ACCESS_KEY_ID={{.Cfg.AccessKey}}
export AWS_SECRET_ACCESS_KEY={{.Cfg.SecretKey}}
export AWS_DEFAULT_REGION={{.Cfg.Region}}

Sous Windows PowerShell : $env:AWS_ACCESS_KEY_ID="{{.Cfg.AccessKey}}", etc. Pour un client mc :

mc alias set classe {{.Cfg.S3Endpoint}} {{.Cfg.AccessKey}} {{.Cfg.SecretKey}}

🏷️ La plateforme est partagée par toute la classe : vos buckets, tables et files portent votre suffixe personnel -{{.Suffix}} (par exemple livrexpress-factures). Les énoncés affichent déjà vos noms complets. Ne touchez pas aux ressources des autres.
